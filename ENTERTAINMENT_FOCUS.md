# SerenityAI - Entertainment Focus (Audio-Only)

**NO HEALTH/MEDICAL FEATURES - Pure Entertainment Only**

SerenityAI has been pivoted to focus exclusively on entertainment and companionship features that are **100% audio-based** with **no health/medical liability**. This makes it safer, simpler, and purely joyful for elderly users.

### Accessibility
- Perfect for vision impairment
- No technology skills needed

- No learning curve

- Natural conversation

## 📞 **How It Works**

### User Side:
1. Pick up phone
2. Call the Serenity AI number
3. Talk naturally
4. That's it!

**No apps. No setup. No technology.**

### Behind the Scenes:
- Twilio handles phone calls
- OpenAI Realtime API for voice AI
- Redis stores preferences and scores
- Natural conversation processing
- Voice responses with emotion
